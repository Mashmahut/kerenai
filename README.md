# התקנת סביבת עבודה עם קלוד קוד, ווינדוס

סקריפט שמכין מחשב ווינדוס לעבודה עם קלוד קוד, בלחיצה כפולה אחת.

## מה הוא מתקין

| שלב | מה | איך |
|------|-----|-----|
| 1 | Git, Node.js, GitHub CLI, Google Chrome | חלון הרשאה אחד של ווינדוס, ללחוץ "כן" |
| 2 | VS Code | לחשבון של התלמידה, בלי הרשאות מנהל |
| 3 | Claude Code | ההתקנה הרשמית מ-claude.ai |
| 4 | אפליקציית Claude לדסקטופ | |
| 5 | התוסף של Claude ל-VS Code, שמירה אוטומטית וגלישת שורות | |
| 6 | תיקיית Projects מחוץ ל-OneDrive | |
| 7 | חיבור לגיטהאב, ושם ומייל לגיט | המייל הפרטי של גיטהאב, כדי שהמייל האמיתי לא ייחשף |

כל מה שכבר מותקן מזוהה ומדולג. אפשר להריץ שוב בלי חשש: הסקריפט רק משלים את מה שחסר.

## הפעלה

1. להעתיק את התיקייה למחשב (דיסק און קי או הורדה)
2. לחיצה כפולה על `install.bat`. **לא** "הפעל כמנהל"
3. בסוף, `check.bat` מציג מה מותקן ומה חסר, בלי לשנות שום דבר

## מה נשאר ידני

- התחברות לקלוד ב-VS Code ובאפליקציה לדסקטופ
- הוספת התוסף של Claude לכרום והתחברות אליו
- פתיחת חשבון בוורסל וחיבור לגיטהאב

## עקרונות

- רק מקורות רשמיים: winget של מיקרוסופט, שרתי ההורדה של כל יצרן, וההתקנה הרשמית של Anthropic
- הרשאות מנהל רק למה שחייב אותן. VS Code וקלוד קוד מותקנים לחשבון של התלמידה
- לא דורס הגדרות קיימות ב-VS Code ולא שם ומייל קיימים בגיט
- אין סקריפט הסרה, בכוונה. הסרה גורפת מוחקת גם הגדרות שהיו במחשב לפני ההתקנה
- `installer.ps1` חייב להישאר באנגלית בלבד. PowerShell 5.1 קורא עברית בקובץ כזה כג'יבריש, והמסוף של ווינדוס מציג עברית הפוכה

## יומנים

כל הרצה נרשמת ב-`%USERPROFILE%\claude-setup-logs\`. אם משהו נכשל, זה הקובץ שמבקשים מהתלמידה.
