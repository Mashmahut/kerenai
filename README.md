# kerenai

התקנה של סביבת עבודה עם קלוד קוד במחשב ווינדוס, בשורה אחת.

## התקנה

**מה צריך לפני שמתחילים**

- מחשב עם ווינדוס 10 או 11, מחובר לאינטרנט
- חשבון גיטהאב. הוא חינמי, ואפשר לפתוח אותו גם באמצע ההתקנה, כשהדפדפן נפתח
- מנוי בתשלום ל-Claude (Pro ומעלה). קלוד קוד לא כלול בתוכנית החינמית

**שלושה צעדים**

1. ללחוץ על מקש ווינדוס, להקליד `PowerShell` וללחוץ Enter. לא לבחור "הפעל כמנהל"
2. להעתיק את השורה הזו (כפתור ההעתקה בפינת המסגרת), להדביק בחלון עם Ctrl+V וללחוץ Enter:

```powershell
irm https://raw.githubusercontent.com/Mashmahut/kerenai/v1.0/get.ps1 | iex
```

3. לעקוב אחרי מה שמופיע בחלון:
   - חלון של ווינדוס ישאל אם לאפשר שינויים במחשב. ללחוץ **כן**
   - כשמגיעים לחיבור גיטהאב: לענות `Y` אם נשאלים, ללחוץ Enter, להתחבר בדפדפן, להדביק את הקוד (Ctrl+V) ולאשר
   - בסוף, Enter אחד פותח את VS Code ו-Enter נוסף פותח את התוסף של Claude בכרום

ההתקנה לוקחת זמן. לא לסגור את החלון באמצע. אם משהו נקטע, מריצים את אותה שורה שוב: היא מדלגת על מה שכבר הותקן ומשלימה רק את מה שחסר.

**אחרי ההתקנה, ידנית**

- להתחבר לקלוד ב-VS Code ובאפליקציה לדסקטופ
- להוסיף את התוסף של Claude לכרום ולהתחבר אליו
- לפתוח חשבון בוורסל ולחבר אותו לגיטהאב

## אם משהו לא עבד

השורה הזו רק בודקת מה מותקן ומה חסר, ולא משנה שום דבר במחשב. מריצים אותה ושולחים צילום מסך של התוצאה:

```powershell
& ([scriptblock]::Create((irm https://raw.githubusercontent.com/Mashmahut/kerenai/v1.0/get.ps1))) -Check
```

כל התקנה נרשמת בקובץ `setup.log` בתיקייה `%USERPROFILE%\claude-setup-logs\`. זה הקובץ ששולחים למי שמלווה אותך.

## מה מותקן

| שלב | מה | איך |
|------|-----|-----|
| 1 | Git, Node.js, GitHub CLI, Google Chrome | חלון הרשאה אחד של ווינדוס, ללחוץ "כן" |
| 2 | VS Code | לחשבון המשתמש, בלי הרשאות מנהל |
| 3 | Claude Code | ההתקנה הרשמית מ-claude.ai |
| 4 | אפליקציית Claude לדסקטופ | |
| 5 | התוסף של Claude ל-VS Code, שמירה אוטומטית וגלישת שורות | |
| 6 | תיקיית Projects מחוץ ל-OneDrive | |
| 7 | חיבור לגיטהאב, ושם ומייל לגיט | המייל הפרטי של גיטהאב, כדי שהמייל האמיתי לא ייחשף |

כל מה שכבר מותקן מזוהה ומדולג.

## הפעלה מדיסק און קי

אפשר גם להעתיק את קבצי הריפו למחשב וללחוץ לחיצה כפולה על `install.bat` (לא "הפעל כמנהל"). `check.bat` מציג מה מותקן בלי לשנות כלום. אם מורידים את הקבצים כ-ZIP, קודם לחלץ ("חלץ הכל") ורק אז להריץ.

## עקרונות

- רק מקורות רשמיים: winget של מיקרוסופט, שרתי ההורדה של כל יצרן, וההתקנה הרשמית של Anthropic
- השורה נעולה לגרסה. היא מורידה תמיד את v1.0 בדיוק, ולא את מה שנמצא בריפו באותו רגע. גרסה חדשה מקבלת תגית חדשה, והשורה בדף הזה מתעדכנת איתה
- זו אותה שיטה של ההתקנה הרשמית של קלוד קוד (`irm https://claude.ai/install.ps1 | iex`)
- הרשאות מנהל רק למה שחייב אותן. VS Code וקלוד קוד מותקנים לחשבון המשתמש
- לא דורס הגדרות קיימות ב-VS Code ולא שם ומייל קיימים בגיט
- אין סקריפט הסרה, בכוונה. הסרה גורפת מוחקת גם הגדרות שהיו במחשב לפני ההתקנה
- `installer.ps1` ו-`get.ps1` חייבים להישאר באנגלית בלבד. PowerShell 5.1 קורא עברית בקובץ כזה כג'יבריש, והמסוף של ווינדוס מציג עברית הפוכה
